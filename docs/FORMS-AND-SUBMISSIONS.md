# Forms and submissions (staff guide)

## The four forms

| Form | Where it is | Who is notified |
| --- | --- | --- |
| **Enquiry**: consultations, partnership, training, newsletter and the free tools (the type is shown on each entry) | Contact page and calls to action across the site | sales@ |
| **Proposal request**, with an optional brief (PDF, DOC or DOCX) | `/contact/proposal` and every service page | sales@ |
| **Career application**, with a CV | Join us | contact@ |
| **Expert network application** | Join us → Expert network | contact@ |

For every submission:

1. The team gets a **notification email** with the reference (for example `SCS-2611-AB12`) and the details.
2. The visitor gets a **confirmation email** from `contact@send.stephencorporateservices-scs.com`. When they reply,
   it reaches `contact@` as normal.
3. The entry is saved in the **submissions view**, with any file stored privately.

Visitors are told: **"We respond within 24 hours."** Please keep to it.

## The submissions view

**https://stephencorporateservices-scs.com/admin/submissions**. Sign in with your Google Workspace account.

- Filter by form and by status. Open an entry to see everything the visitor sent.
- **Status**: set each entry to *New* → *Reviewed* → *Replied* → *Closed* as you work on it, so everyone can see
  what's done.
- **Files** (CVs, briefs): click the file link. It works for 15 minutes, then a fresh link is needed (reload the
  entry). Download a file only when you need it, and delete your local copy when you've finished.
- Reply from your normal Workspace mailbox, quoting the reference.

## Keeping personal data safe

- Entries and files are **deleted automatically six months** after they arrive, as the Privacy Notice says. If you
  need to keep something longer (for example a client you're now working with), copy what you need into the client
  file first.
- Never forward a CV or a brief outside the company. Never paste personal data into chats, analytics or shared
  documents.
- Analytics never receives names, emails, phone numbers, messages or files.
- **Requests from a person about their data** (to see it, correct it or delete it) arrive at info@. Pass them to the
  owner the same day. The developer can find or delete a person's entries early on request.

## When a form doesn't work

Visitors always see the phone number (+234 812 813 8222), WhatsApp and email as alternatives, so no enquiry is
lost. Tell the developer, with the time and the page. `docs/DEPLOYMENT.md` §5 lists the usual causes.

Spam: the forms are protected by Cloudflare Turnstile, a hidden trap field and a limit of about five sends a minute
per visitor. Mark obvious spam as *Closed*; it's deleted with everything else after six months.
